# Protocolo do cliente: resultados de análise

A pasta [endpoint-reference](endpoint-reference/) preserva o contrato
reconstruído a partir do cliente Global 9.0.0: rotas, payloads,
inicialização, arena, summons, amigos, mapas e CDN. As conclusões de
campo devem ser lidas com as classificações de confiança originais.

- [Contrato e índice de endpoints](endpoint-reference/README.md)
- [Pesquisa de contrato anterior](EARLY_CONTRACT_ANALYSIS.md):
  inventário de trabalho, **não fonte normativa** se divergir da
  análise posterior.
- [Campos de requisição ainda não mapeados](unhandled_request_fields.json).
- [Notas por grupo de ação](../request-analysis/).

Não se trata do contrato do motor JNI da versão Offline 0.1.30,
nem é garantia de compatibilidade entre builds, ambientes ou saves.
