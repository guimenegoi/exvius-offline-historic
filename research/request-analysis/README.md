# Resultados das investigações de ações

Os quatro pares `*.notes.md` e `*.report.json` preservam
mapeamentos de campos de requisição, evidências estáticas e lacunas
dos grupos arena, expeditions, modes e shops. Os arquivos JSON são
**relatórios de pesquisa**, não tráfego autenticado para replay nem
esquemas de resposta aprovados.

Muitas hipóteses provêm de desassemblagem de uma biblioteca AArch64
v9.0.0. Trechos de código, endereços e nomes de campo não demonstram
que um servidor real reproduziria o comportamento original.

Os prompts, scripts auxiliares e dumps intermediários não foram
preservados: apenas notas e resultados de investigação.
